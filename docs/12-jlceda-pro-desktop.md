# 嘉立创EDA专业版桌面端操作手册（本机 4.1.71）

面向本项目的实际操作：怎么建工程、怎么画原理图、怎么布局布线、怎么设规则、怎么出生产文件、怎么用命令行驱动它。

> 版本核对：本机注册表登记 `嘉立创EDA(专业版) 4.1.71`，安装在 `E:\Program Files\lceda-pro\`。
> 注意 `C:\Program Files\lceda-pro\` 下另有一份 **3.2.69** 的旧安装，`--help` 不会打印 CLI 帮助而是直接启动界面。**脚本里一律写全路径 `E:\Program Files\lceda-pro\lceda-pro.exe`**。

## 1. 运行模式与数据目录

| 模式 | 登录 | 库 | 工程 | 说明 |
|---|---|---|---|---|
| 在线 | 需要 | 云端系统库 + 个人库 | 云端，可协作 | 需联网 |
| **半离线**（推荐） | 不需要 | 本地库 + **可用云端系统库** | 本地 | 日常设计与本项目一致 |
| 全离线 | 不需要 | 仅本地库（内置约 1 万器件） | 本地 | 无系统库、不能在线下单 |

数据目录：`文档\LCEDA-Pro`（本机为 `E:\用户\LCEDA-Pro`），其中：

- `projects\` 工程目录，`projects\<工程名>\<工程名>.eprj3`；
- `libraries\` 本地库；`config.json` 里 `APP_PROJECT_DIR` 是工程根目录列表；
- `logs\`、`cache\`、`projects-recovery\`。

该目录**不要手工改动**；清缓存走 设置 → 其他设置 → 清除缓存。

## 2. 界面结构

```
顶部菜单 / 工具栏
┌──────────┬──────────────────────────┬────────────┐
│ 左侧面板  │        画布               │  右侧面板   │
│ 图页/对象 │  (原理图 / PCB / 面板)     │ 属性/过滤   │
```

- PCB 底部还有一条**图层栏**：视图 → 窗口 → 图层栏。

## 3. 工程与文档层级

结构是 **工程 → 板子(BOARD) → 原理图(SCH/图页) + PCB**，另有独立的**面板(PANEL)**文档。

- 新建工程：`Shift+N`；多板工程用 新建 → 板子，一块板自动配一套原理图 + PCB。
- 多页原理图：文件 → 创建原理图 / 创建图页；`Page Up/Page Down` 翻页。
- **一块板只对应一块 PCB**，不能把多张原理图选择性转到某个 PCB。
- **CBB 复用模块**：文件 → 新建 → 复用模块（只放端口）；或 设计 → 生成/更新图块符号（自下而上）；或 放置 → 复用模块拉框。3.1 起位号自动拼接（`CBB1` + `C19` → `C19CBB1`）。
- **库模型**：器件 = 符号 + 封装 + 3D。放置时器件自动进入**工程库**（模板化），避免个人库更新污染设计；要回写个人库用"另存为个人"。
- 归档：`文件 → 另存为本地` 生成 `.epro`（归档包，不能双击，需从开始页导入）；`eprj` 是旧离线单文件。

## 4. 原理图流程

| 步骤 | 操作 | 要点 |
|---|---|---|
| 放器件 | `Shift+F` 或底部面板 `S` / `\` | 离线模式本地库**只支持模糊搜索，关键词 ≥3 字符** |
| 连线 | `Alt+W`（专业版；标准版是 `W`） | 导线自动吸附引脚端点 |
| 命名网络 | `Alt+N` 网络标签 | 也可直接给导线命名，导线名即网络名 |
| 总线 | `Alt+B` | 总线入口用总线接入标识 |
| 位号 | 设计 → 分配位号 | 设置-通用 可开"放置/粘贴时自动分配" |
| 封装绑定 | 选中 → 右侧属性 → 封装管理器 | **引脚编号必须与焊盘编号一一对应**，否则无法转 PCB |
| 图框 | 设计 → 设置工程图纸 | 属性里点"图纸符号"可换幅面 |
| 检查 | 设计 → 检查 DRC | 紫色虚线=库过期，用"设计 → 更新工程库" |
| 网表对比 | 设计 → 网表对比 | 支持 AD/PADS/Allegro/Zuken/嘉立创 enet |
| 装配变量 | 工具 → 装配变量（`.evar`） | 用于"同一板不同贴装配置" |

## 5. PCB 流程

### 5.1 层

- 工具 → 图层管理器（或右侧图层面板右上角图标）：层数、颜色、类型、透明度、物理堆叠。
- **信号层=正片**（画线处留铜），**内电层=负片**（画线处去铜），但**导出 Gerber 时内电层按正片输出**。
- 内电层分割只能用**折线**且必须闭合，分割后**手动重建**（或 `Shift+B` 重建全部铺铜）；专业版不会自动重建内电层。
- 物理堆叠目前只做记录与 3D 预览，不参与阻抗计算；可导出/导入 XLSX 叠层表。
- 自定义层最多 30 个，默认不进 Gerber。

### 5.2 布局

- 板框：放置 → 板框（`POLY`，layerId 11）；**铺铜要求板框闭合**。
- 布局菜单：对齐（可指定参考对象）、等距分布、旋转、翻面、偏移、互换位置、组合、自动布局、阵列（编辑 → 阵列对象）。
- 飞线：视图 → 飞线；单网络 `Ctrl+R`；网络面板的眼睛图标。
- 吸附：编辑 → 吸附（`Alt+S`），可吸焊盘/过孔/线中心，**吸附距离默认 8 mil，被改成 0 就"吸附失效"**。

### 5.3 布线

- 单路布线 `Alt+W`；推挤布线；差分对布线 `Alt+D`；等长调节 `Shift+A`；扇出；自动布线；清除布线。
- 布线中：`L` 循环拐角，`+/-` 加粗减细，`Shift+W` 切换常用线宽，`Shift+V` 切换常用过孔，`Alt+V` 放过孔。
- 布线模式可选"忽略/阻挡"：连不上时先切"忽略"再查 DRC，不要用"忽略"掩盖问题。
- 过孔：`Alt+V` 普通过孔；缝合孔/包地孔另选；盖油=阻焊扩展填负值，开窗=正值。
- 泪滴：工具 → 泪滴，可设"布线时自动添加"；加不上多为线段过短、圆弧导线或该处已有 DRC 违反。
- 覆铜：放置 → 铺铜区域；属性控填充样式（实心/网格）、保留孤岛、**制造优化**（默认开）、优先级；间距与热焊在 设计规则-铺铜；铺铜内缩在 安全间距-边框与铺铜。

### 5.4 检查与可视化

- 设计 → 检查 DRC（可"自定义"只勾部分规则）；结果面板点条目定位。
- 测量 `Alt+M`；长度标注 `Alt+N`；翻转板子 `Alt+F`；层亮度 `Shift+S`；隐藏铺铜 `Shift+M`。
- 3D：视图 → 3D 预览 / 3D 外壳预览；可导 STEP；3D 模型管理器管模型绑定。

## 6. 设计规则（Design Rules）

入口：**设计 → 设计规则**。左下有嘉立创预设工艺可一键套用，也可"设为新建 PCB 默认设置"。

### 6.1 四大类

| 类 | 内容 |
|---|---|
| **间距** | 安全间距（网络↔网络矩阵）、其他间距（元件↔元件、插件焊盘↔SMD、钻孔↔钻孔，填 0 = 不检查） |
| **物理** | 导线（最小/默认/最大线宽）、网络长度、盲埋孔、过孔尺寸（外径/内径 min/def/max）、高度规则 |
| **平面** | 内电层规则、铺铜规则（网络间距、到边框间距、焊盘连接方式 发散/直连/无、发散线宽与间距与角度）。铺铜比内电层多一个"导线连接方式" |
| **扩展 / 网络** | 助焊扩展、阻焊扩展（**不盖油就把过孔阻焊扩展填成小于孔径的负数**）、网络规则（按网络分配）、网络-网络规则、区域规则、不同层规则 |

### 6.2 规则体系的四层结构（与文件格式一致）

1. `RULE_TEMPLATE` — 规则模板名（如 `JLCPCB Capability(...)`）。**当前实现里它只是"来源标识"，不叠加生效**。
2. `RULE` — 一条具体规则：`ruleType` + `ruleName` + `ruleState`（0 普通 / 1 默认 / 2 停用）+ `ruleContext`（数值）。
3. `RULE_SELECTOR` — 规则作用在谁身上：网络类 `NET_CLASS`、网络 `NET`、层 `LAYER`、区域 `REGION`、封装 `FOOTPRINT`、元件 `COMPONENT`、覆铜 `POUR`、差分对 `DIFF_PAIR`、等长组 `EQ_LEN_GRP`。
4. `ruleOrder` 优先级，**数值越小越优先**：0 元件 → 1 封装 → 2 区域 → 3 网络-网络 → 4 网络 → 5 层。

设成默认规则的会置顶且不能删、不能复制；普通规则可复制（`Ctrl+C`，名称自动递增 `_n`）、双击改名。

### 6.3 优先级实践

具体对象规则 > 网络类 > 默认规则。所以：

- 电源/大电流 → 建**网络类**（如 `PWR`）单独给宽线；
- USB 差分 → 用**差分对**规则给线宽/间距；
- 开关节点/晶振 → 用**区域规则**（约束区域）局部收紧间距；
- 想全局改线宽，改"默认规则"里的导线规则，不要逐个网络改。

## 7. DRC

- 入口：设计 → 检查 DRC；原理图与 PCB 各有一套。
- PCB DRC 除了几何规则，还会**把 PCB 网表与原理图网表做比对**——只要器件与焊盘网络一致就能过。
- 常见"改了没反应"：规则没启用 / 该类型规则被更高优先级覆盖 / 区域规则未包含该图元 / 实时 DRC 开关被关掉。
- 高度规则**不支持实时 DRC**，必须手动跑检查。

## 10. 命令行与扩展 API（桌面端独有）

4.1.60 起客户端内置 CLI，能力 = 图形界面能做的几乎都能脚本化。

```powershell
$L = 'E:\Program Files\lceda-pro\lceda-pro.exe'
& $L --help                       # 第一行是版本，如 JLCEDA Pro 4.1.71.7a7261be
& $L doctor                       # 探测本地桥接：ok / connected / versionMatch
& $L open --path 'E:/.../X.eprj3' # 返回 sessionId；--headless true 隐藏窗口
& $L session list                 # 列出会话（origin = cli / user）
& $L session close --session <id> --destroy
```

核心是 `invoke`：在会话里执行一段 JS，直接调 `eda.*` 扩展 API。

```powershell
& $L invoke --session <id> --ext-uuid eda --code "return await eda.pcb_Net.getAllNetsName()"
& $L invoke --session <id> --ext-uuid eda --args '{"ref":"R1"}' --code 'return __CLI__.args.ref'
& $L invoke --session <id> --ext-uuid eda --code "$(Get-Content .\probe.js -Raw)"
```

- **必须带 `--ext-uuid eda`**，否则拿不到完整的外部交互权限（读写文件等）。
- 路径用**正斜杠**；`--timeout` 默认 60000 ms，批量/自动布线要调大。
- 返回统一信封 `{ok, value, logs, durationMs}`，只看 `ok`。
- 改完等 5–10 秒再查状态（DRC/网表/渲染）。
- `--mcp stdio` / `--mcp http --port 3030` 可当 MCP 服务器给 AI 助手用。

查 API 与格式（自学入口）：

```powershell
& $L doc api                                        # 全部类
& $L doc api --class-name PCB_Document              # 该类的方法
& $L doc api --class-name PCB_Document --method-name autoRouting   # 方法签名+示例
& $L doc format --class-name TPcbBase               # 设计文件格式字段
```

常用 API：`dmt_Project.createProject/openProject`、`dmt_EditorControl.openDocument/getCurrentRenderedAreaImage`、`sch_PrimitiveComponent.create/createNetFlag/modify`、`sch_PrimitiveWire.create`、`pcb_Document.importChanges/autoLayout/autoRouting/save`、`pcb_Drc.check`、`pcb_ManufactureData.getGerberFile`、`sys_FileSystem.saveFileToFileSystem`。

本仓库的封装：`hardware/pcb/robot_electronics_v4_1_bottom_ports/desktop_cli.py`（自动解码 UTF-8/GB18030、留证到 `evidence/official_cli/`、大参数走临时文件规避 32K 命令行限制）。

## 11. 容易踩的坑

1. `C:\Program Files\lceda-pro` 是旧版（3.2.69），**没有 CLI**；用 `E:\Program Files\lceda-pro`。
2. 全离线模式没有云端系统库，本项目的器件（立创编号）可能搜不到 → 用半离线。
3. 内电层不会自动重建，改完必须 `Shift+B` 或手动重建，否则 Gerber 是旧的。
4. 物理堆叠不参与阻抗计算，下单时要重新选叠层。
5. 吸附距离被改成 0 会导致"怎么都对不齐"。
6. BOM 导出前不点"恢复默认"，会把"属性设为不导出"的字段带进去。
7. 在线下单只支持在线模式；打样免费券要求全流程在本工具内完成。
