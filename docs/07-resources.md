# F407与S3资源、引脚预留

## 是否足够

当前任务不在F407上处理视频，ZGT6提供的1MB Flash、192KB SRAM、定时器与串口总体能支持这一控制分工。芯片SRAM有不同访问限制，尤其CCM不能当DMA通用缓存。资源充足是基于关闭冲突外设、正确复用和有限数据量的设计判断，不是整机固件编译或实时性测试结论。

正点原子最小系统板的板载SRAM、SPI Flash、EEPROM、SD和调试连接会占用资源。下面是**初步引脚草案**，不得直接按此一次性接全设备；须对照实际板原理图、封装AF表和到货版本逐项冻结。

|功能|候选资源/引脚|注意|
|---|---|---|
|轮编码器1|TIM2 PA15/PB3|释放JTAG相关复用，保留SWD；注意板载Flash共享|
|轮编码器2|TIM3 PA6/PA7|确认输入电平与滤波|
|轮编码器3|TIM4 PB6/PB7|占用后不能再作该路I2C|
|轮编码器4|TIM8 PC6/PC7|确认编码器通道映射|
|四轮PWM|TIM1 PE9/PE11/PE13/PE14|与板载外部SRAM总线冲突，必须禁用FSMC并保持SRAM不选中|
|四轮方向|PG11/PG12/PG13/PF8/PD3/PD6/PD7/PE2|对应8路IN，按板丝印核对电机顺序|
|滑台STEP/DIR/ENA|TIM9 PE5 / PE6 / PE3|TB6600输入电路、电流及电平另核验|
|泵/搅拌PWM|TIM10 PF6 / TIM11 PF7|只是控制信号，需独立功率驱动|
|S3通信|USART2 PA2 TX / PA3 RX|交叉连接到S3 RX/TX，3.3V共地|
|总线舵机|USART3 PB10/PB11|协议、电平、半双工收发器待定|
|语音模块|UART4 PC10/PC11|不用SD复用冲突功能|
|屏幕|SPI2 PB13 SCK / PC2 MISO / PC3 MOSI|CS PB12、DC PG6、RST PG7、背光控制PG8；MISO可按屏需求省略|
|限位/到位|PF0/PF1/PF2/PF3|初步按轮询输入，不能都与急停抢同一EXTI线|
|急停状态输入|PE0 EXTI0|还需硬件禁止/切断设计|
|电池电压|PB0 ADC，经新增分压与保护|酷点板没有已确认的电池ADC引出，禁止12V直连|
|ToF候选总线|I2C3 PA8/PC9，或独立UART|以TOF050C准确协议为准|

原草案PG15用作STBY，但实购酷点板没有确认对外STBY控制口，因此取消该“已可接线”结论，暂留PG15。PA1/PA4、PF4/PF5等历史超声波/红外引脚也未固定占用。

## 必须先处理的板载冲突

- 不启用外部SRAM/FSMC，保证SRAM片选PG10处于不选中状态；不要使用厂商演示里依赖外部SRAM的堆。
- 如编码器使用PB3，板载SPI Flash必须不被选中；PB14片选保持无效，禁用相应SPI访问，并核对其对PB3的实际负载。
- PA13/PA14留SWD；PA0/PE4板载按键、PF9/PF10指示灯以及PB8/PB9板载EEPROM不随意当作空闲排针。
- HSE/RTC相关引脚、板载跳线和电源口以实际板图为准；物理未引出的引脚不算可用接口。
- 编码器供电支持3.3V/5V的商品说明不等于AB输出都兼容3.3V MCU；确认编码器输出类型与驱动板透传电平，必要时电平转换。不能仅用电机插头可插入来判断信号安全。

若订单电机确为11线×30减速比，则输出轴一圈330个AB单通道周期，四倍频可得1320计数；实际应手转一圈验证，不能把线数、周期和四倍频计数混用。

## 三只ToF接法决策

先确认050C的串口/I2C模式和电平。可改I2C地址且可独立初始化时共享总线；不能改地址则需要I2C复用器或独立串口。若选择三个UART，重新分配上述预留串口并核对USART1调试口跳线。不要假设已购模块支持XSHUT或可直接并联三个相同地址。

## S3预留

候选UART为GPIO17 TX、GPIO18 RX，对接F407 PA3 RX、PA2 TX。GPIO19/20留原生USB；N16R8相关GPIO35/36/37避免使用，启动配置脚和板载RGB脚不随意分配。原理图与实物USB供电配置需单独核对。

后续低速GPIO设备可通过扩展器增加，但高速编码器/PWM不应随意移至低速I2C扩展器；扩展接口还必须核算电源、总线带宽、中断、DMA与任务时限。当前不承诺可无限增加设备。
