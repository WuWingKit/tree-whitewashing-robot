# V5 原孔径轻量支架 · SW2020

## 与原件的对应关系

本版依据已使用的紧凑双耳相机壳、TOF050C 背板V2重做支架。相机壳和TOF背板继续使用，均不需重打。支架使用圆孔，已有原件中的螺丝间隙已经计入孔径，不再二次加大。

|接口|原件孔径 / 孔距|V5支架孔径 / 孔距|连接方式|
|---|---|---|---|
|相机双耳|φ3.1 / 48|φ3.1 / 48|2颗原M2.5×10，保留5mm夹板厚度|
|TOF背板外孔|φ3.6 / 27×18|φ3.6 / 27|只连接下排两孔，原背板上排留空|
|TOF模块到背板|原模块φ2、14.4孔距；原背板φ2.2|本次不改这一组孔|沿用原M1.6及原5mm间隔柱|

相机原始PCB为32×32、四孔28×28；现用壳主体40×40×18，含双耳60×40×18。双耳固定孔的48mm间距决定了支架两臂的位置。TOF原始尺寸图给出20×11、孔距14.4、φ2，现用背板36×26×3、外孔27×18。源STEP和SLDPRT的孔径孔位均已独立读取核对，报告在“验证”。

## 打印文件和数量

只打印 `打印文件_只打印这两个`：

- `01_V5_相机双耳短叉支架_孔3.1距48_定尺寸_打印.STL`：1件。
- `02_V5_TOF双臂短支架_孔3.6距27_定尺寸_打印.STL`：2件，同款，无需镜像。

STL为mm，按100%导入，已按底脚朝热床摆放。切片后包络应为相机56×14×28、TOF35×12×30。不要通过整体缩放调整孔径，否则48/27孔距也会改变。

“可选_先试孔径孔距”内有两个8mm高的水平孔试片，分别复现相机φ3.1/48、TOFφ3.6/27，孔轴与支架底脚朝下打印时相同。可先各打印1片，配原螺丝和原壳/背板试孔；它们是可选试片，不装车，也不计入3件正式打印件。

## 打开与验证

完整解压后打开 `V5_整车_滑台_相机TOF短臂支架.SLDASM`，保留“参考”和“新支架零件”。总装97个平级组件，原车作为90实体参考、滑台电机朝上。原件验配小装配中另有16组件相机验配、10组件TOF验配，可轻量查看具体连接。

已验证：原STEP和SLDPRT孔径/孔位；支架圆孔与原壳/背板同径同轴；解析体积、闭合单连通STL、mm比例、底脚3厚及打印包络；新零件保存重开、完全定义且无Fix的草图；整车和两个小验配总装零实体干涉；USB向上和两处下插走线检具零干涉；原六车板孔文件一致；原件未修改。

可从0.2mm层高、4圈壁、4～5层顶底试装。TOF臂外缘比底脚宽出每侧1.5mm，切片时查看该处并按需局部支撑，圆孔也检查桥接。尚未完成实物打印试装、承载/振动寿命测试，也没有完整夹爪/喷嘴/软管运动扫掠或真实USB插头模型。
