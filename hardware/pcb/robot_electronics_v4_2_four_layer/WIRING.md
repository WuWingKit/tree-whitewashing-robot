# V4.2 接线与安装说明

> 2026-11-20 程序更新：两端配套版本 `0.4.0-upper-usb-tof` 已实现 CH1=PA4 搅拌器、CH2=PG12 水泵的高电平有效网页开关和输出报告，保留三路 TOF 与 USB 相机诊断。使用 `pcb_v2`，只完成编译/主机测试，未烧录。接线、烧录和操作见 [联合测试说明](../../../../firmware/remote_control/BENCH_TEST_20261120.md)。本段更新优先于下文早期功能状态。


两块 PCB 的板框均为 100×100 mm，厚度 1.6 mm；**两板均为四层**（L1/L4 走线，L2/L3 为整板地内层：控制板 GND、电源板 P_GND，叠层 JLC04161H-7628）。TB6612/MD04 单独固定在小车上，控制板只保留接线接口。上限位改为已从主控插座引出的 PB4；四路IRF控制改为PA4、PG12、PA5、PD13；其余 GPIO 保持原分配。已更新 pcb_v2 配置、三份生成头文件，并编译 STM32 PCB_V2 固件。

STM32 和 ESP32 元件面朝上，长针向下插入 TOP 排母。扩展排针、USB 母座、12组3V3/5V供电排针、4个绿色螺丝端子及部分功能接口装在 BOTTOM。控制板下方建议预留至少 25 mm，用于连接器和线缆弯曲；STM32 左侧突出板框约 8.5 mm，SWD 排针从板边缺口避让。

3V3 与 5V 各六组 2.54 mm 双针接口，每组 Pin1 为电源、Pin2 为 GND。丝印的电压标签靠电源针，GND 靠地针。J_5V_IN 接 MD04 提供的逻辑 5V。电源板不另加 5V 降压。

两组 USB 母座分别对应现有 USB Hub 的两个下行口，VBUS、D−、D+、GND 一对一连接；它们并不构成 USB Hub。不要将不同 5V 电源直接并联，调试板自带 USB 供电前先断开对应电源跳线。

J_SERVO 使用 5264-3P，针序为 1=I/O、2=5V、3=GND。步进接口为共阳开集电极控制，PUL/DIR/ENA 的负端是控制信号，不是电源地。

四颗指示灯通过电阻直接检测相应电源，无 MCU 控制脚。24V OUT 只表示输出端有电：升压停用时可能仍有接近 12V 的输出，不能作为精确的 24V 达标判据。

独立电源板：DC 5.5×2.1 mm 中心正极与螺丝端子分别经保险丝/二极管接入；保留独立 12V 和升压 24V 输出。第二组电池及负载总电流尚未确认，所以此版本按样机审查，不声明整板额定电流。滑台驱动器需按 28HS30-0604A-013 的每相 0.6A 配置，供电 24V 不等于把 24V 直接施加到电机绕组。

所有单片机扩展针脚原板名见 PIN_SILK_MAP.csv，含 144 个针脚；所有焊盘网络、坐标见 PINOUT.csv。采购数量区分 FIT 与 DNP，已有模块不应重复采购。

## V4.2 接口用途与装配

控制板的12组3V3/5V排针和4个绿色端子全部位于BOTTOM。绿色端子按原TOP平面图的右侧从上到下为滑台脉冲、方向、使能、5V电源输入；前三组为5V光耦控制信号，不可接12V/24V电池。孔位和编号保持，绿色端子出线面朝板边。

电源板元件面朝向观察者、DC输入在左时，右侧四个绿色端子从上到下为24V滑台、12V滑台预留、12V搅拌泵模块、12V预留。每组Pin1为正电源，Pin2为GND。左侧绿色端子是12V电池输入。

IRF CH1约定接搅拌，CH2接水泵，CH3/4预留；它们是逻辑控制接口。搅拌器和水泵负载接外置IRF540模块的负载输出；电源板的12V搅拌泵模块口接该模块的电源输入。动作流程尚需后续程序实现。

上限位由PB8改为PB4，因为当前STM32插座没有PB8。固件选`pcb_v2`（宏`ROBOT_WIRING_PROFILE=2`），已重新生成全部3份引脚头文件并编译STM32该配置；未烧录设备。

完整每组接口用途见 `INTERFACE_FUNCTIONS.csv`。

四路IRF最终引脚：CH1=PA4（搅拌）、CH2=PG12（水泵）、CH3=PA5（预留）、CH4=PD13（预留）。这些引脚均已从当前STM32模块插座引出，并完成PCB连通性与固件配置核对。


## V4.2 四层修订

控制板和电源板均为100×100 mm四层板，标称厚度1.6 mm，生产叠层选JLC04161H-7628，外层1oz、内层0.5oz。两内层分别为GND与P_GND整面铺铜；逻辑地与功率地的原有连接方式不变。控制板ESP32天线区在四个铜层上禁铜。USB1/2均保留ESD保护，耦合段按10.4mil线宽、7mil间距设计，嘉立创官方SI9000计算约90.46Ω；芯片及接头扇出为短距离过渡，尚未做实板USB眼图测试。原接口针序、GPIO、连接器正反面和安装孔位保持V4.1配置。
