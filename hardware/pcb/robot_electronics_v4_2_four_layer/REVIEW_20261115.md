## 2. USB 差分：几何我量过了

| 项 | 声称 | 实测 |
|---|---|---|
| 长度（D+/D− 各） | 17.006 mm | 17.006 mm（4 条完全一致） |

| 阻抗 | 90.46 Ω | 嘉立创官方计算引擎返回 90.4624 Ω（模型 `DiffEdgeCoupledCoatedMicrostrip1B`，H1=8.2834 mil、Er=4.4、T1=1.6 mil、S1=7 mil，`dResultValid=1`） |

计算请求与结果都留了证据（`evidence/jlc_calc/calculation-request.json` / `calculation-result.json`），参数与板上实际叠层一致，不是随手填的。

**边界要说清**：90.46 Ω 是**截面计算**，不含连接器扇出、ESD 焊盘、共面结构和实际蚀刻偏差；所以它是"设计意图达标"，不等于眼图或误码率达标。工程里也如实写了 `physical_tested: false`。

## 3. 四层化怎么避开了上次的坑

上次我把内电层设成 `PLANE`，电源板因为地网叫 `P_GND` 而绑不上网络，只能回退。这次改用**信号层 + 显式网络铺铜**：内层类型是 `SIGNAL`，上面直接放 `GND` / `P_GND` 铺铜。好处是网络由铺铜自己携带，不依赖"层名=网名"的隐式绑定，两板都能正确落地，而且可编辑、可重建。

这是正确解法，比我上次的方案稳。

## 5. 必须改的问题

### P1-1　`WIRING.md` 第 3 行还写着"电源板两层"

原文：
> 两块 PCB 的板框均为 100×100 mm，厚度 1.6 mm；**控制板四层**…**电源板两层**。

实际电源板已是四层（另存工程、DRC、Gerber、丝印都是 4 层）。这句是从 V4.1 抄过来没改，会直接误导装配和下单。**必须改成"两板均四层"**。

### P1-2　固件默认配置仍是 `legacy`（V4.1 的 P0 未处理）

- `firmware/remote_control/tools/build_stm32.py:56` → `default="legacy"`
- `firmware/remote_control/stm32/App/robot_pinmap.h:8` → `ROBOT_WIRING_PROFILE ROBOT_WIRING_LEGACY`

V4.2 的 `WIRING.md:90` 写了"固件选 pcb_v2"，但**不传 `--profile` 就是旧接线**。四层板插上旧固件，电机/ToF/IRF 全部错位。建议把默认值改成 `pcb_v2`，或编译时断言板卡版本。

### P1-3　ToF 上拉 R1–R6 仍全部 DNP，仍无说明

V4.2 的 BOM 与 V4.1 逐位号一致（127 行、FIT 116、DNP 11），R1–R6 这六只 4.7 kΩ 仍标 DNP。若 TOF050C 模块自身没有上拉，三路 I²C 全部不通。至少要在 README 写一句"依赖模块自带上拉，实测确认"。

### P1-4　控制板 5V 输入与舵机 5V 仍无保险/TVS

BOM 没有任何新增保护器件。MD04 的 5V 直接进 `SYS_5V`，舵机 5V 也直接取自该网络。加一颗自恢复保险 + SMBJ5.0A，成本几毛钱，比换 MCU 便宜。

## 6. 建议（不阻塞打样）

- **P2-1** 电源板 IRF 模块仍只有通道丝印（搅拌 CH1…），**没有 65×65 模块外框**。四角长槽有了，但装配时无法判断模块朝向与边界，建议补一圈外框丝印。
- **P2-2** 叠层记录合计 1.571 mm（0.035+0.2104+0.0152+1.065+0.0152+0.2104+0.035），成品 1.6 mm 由阻焊补齐。下单时务必选 `JLC04161H-7628` 模板，不要手填厚度，否则阻抗会偏。
- **P2-3** STM32/ESP32/IRF 模块本体仍无 3D 实体（`3D_MODEL_BINDINGS.csv` 与 V4.1 同名同大小），装配干涉只能靠二维丝印判断。
- **P2-4** USB 建议在打样时加一段**测试 coupon**（同叠层、同线宽间距），否则 90 Ω 只有计算值，没有实测手段。

## 8. 结论

四层化本身做得干净：叠层、内层网络、天线禁铜、USB 长度与间距都对得上，DRC 我独立复跑也是 0/0，Gerber 内层有实铜。这是一版可以下单的工程。

**为什么 5V 保护没做**：给 `J_5V_IN` 加 PPTC + TVS 需要在原理图上新增两个器件、把 `SYS_5V` 拆成"输入侧/负载侧"两段网络，再在已经布好线的 100×100 双面元件区里找位置、走线。API 只能按库器件创建元件，而本机这条通道对最基础的直线/文本图元都返回"参数不正确"（已实测三次，见 `evidence/official_cli/v42-fill-probe*`、`v42-irf-outline*`），无法在没有画布反馈的情况下安全落位。硬做容易把 5V 与相邻网络短接或留下悬空网络，所以停在这里，留给 GUI 里一次 10 分钟的增量修改。

如果需要，下一步可以：在 GUI 里从立创库放一颗 0805 自恢复保险（如 C883410 类）串在 `J_5V_IN.1` 与 `SYS_5V` 之间，再并一颗 SMBJ5.0A 到 GND；改完重新导出 Gerber 与 PDF 即可。
