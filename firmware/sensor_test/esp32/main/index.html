PCB 的 USB 母座对应 J_HUB1/2 转接口；每路四根线接 Hub 同一路下行口的 5V、D−、D+、GND。Hub 上行口接 ESP32-S3 原生 USB/OTG，COM 口只用于烧录和日志。
