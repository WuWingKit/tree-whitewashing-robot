# 2026-11-09实机记录

ESP32-S3 N16R8与正点原子STM32F407ZGT6。以下不包括非零车轮运动、电流或温升测试。

|测试|结果|
|---|---|
|STM32串口烧录|COM9，ROM Bootloader 0x31，ID 0x0413；原第0扇区先备份，只擦除第0扇区，写入9612字节，逐字节回读一致|
|ESP32 USB初始化|COM10确认S3、16MB四线Flash；写入0.2.0-ota应用并通过工具哈希校验|
|UART通信|持续收到F407：online=1、armed=0、estop=0、L=0、R=0|
|登录鉴权|未登录OTA准备请求被HTTP 401拒绝|
|目标检查|错误目标被HTTP 400拒绝|
|维护联锁|零指令启用后进入维护，F407取消启用、输出为0；ARM/DRIVE被HTTP 423拒绝|
|镜像类型|USB合并镜像被拒绝，未激活备用槽|
|SHA256|故意使用错误校验值，更新被拒绝，当前应用地址与版本不变|
|会话令牌|错误令牌被HTTP 409拒绝|
|真实OTA|Wi-Fi上传750880字节，校验成功并重启；启动槽从0x10000切到0x150000|
|启动自检|OTA状态为ESP_OTA_IMG_VALID（2），版本0.2.0-ota|
|升级后停车|STM32在线、未启用、无旧会话、左右输出为0|
|中断上传|声明完整长度，实际仅发送65536字节后关闭TCP；更新中止，原运行槽保持不变，仍锁定遥控|
|中断后取消|显式取消维护后，STM32仍在线、未启用、零输出|

测试电脑临时连接机器人热点，每轮后恢复原网络。未公开家庭网络配置、设备OTA密码、旧程序备份或设备唯一编号。

指令只包含STOP、ARM及左右为0的DRIVE，没有让车轮旋转。网页控制脚本回归测试、OTA镜像头与兼容标记的C测试通过；真实OTA通过与网页相同的HTTP接口执行，文件选择界面的完整人工操作尚未单独录制。

不能将这些结果推广为断电全覆盖、安全认证、驱动电流匹配或整机自动作业通过。STM32 IAP/OTA尚未实现。
